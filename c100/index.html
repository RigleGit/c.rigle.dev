Lo que aprenderás

Fundamentos sólidos de C

Variables, tipos de datos y operadores para entender cómo trabaja C desde la base.

Control de flujo y lógica

Condicionales y bucles (`if`, `switch`, `for`, `while`) para resolver problemas reales paso a paso.

Funciones y recursividad

Descomposición de problemas, reutilización de código y técnicas recursivas con criterio.

Punteros y memoria dinámica

Gestión de direcciones, `malloc/free` y buenas prácticas para evitar errores comunes.

Arrays, cadenas y estructuras

Modelado de datos con arrays, strings y `struct` para construir soluciones más completas.

Ficheros y entrada/salida

Lectura y escritura en archivos, además de manejo de recursos para programas robustos.

Estructuras de datos y algoritmos

Listas, pilas, colas, árboles, ordenación y búsqueda para organizar y recorrer los datos.

Concurrencia y redes

Hilos POSIX, mutex, sockets TCP y UDP, y un cliente HTTP básico.

Seguridad y manejo de errores

Límites, entradas no fiables, desbordamientos y limpieza de recursos.

Proyectos y herramientas

Una agenda de contactos, una calculadora postfija y un apéndice con depurador, sanitizers y Makefile.

No es solo teoría: es práctica real

Lee el enunciado, intenta resolverlo, compila y prueba con casos concretos. Después compara con la solución y modifica el programa con los retos de «Un paso más». Los apartados «Comprueba el resultado» te ayudan a verificar lo que hace tu código.

Necesitas un editor, un compilador de C y una terminal. Los bloques de hilos y redes requieren Linux, macOS o Windows con WSL, porque utilizan interfaces POSIX.
